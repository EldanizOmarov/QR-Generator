# QR Studio

A free, no-signup QR code generator. Turn a link or text into a QR code, add a center logo, customize colors, and download as PNG or SVG. Everything runs in your browser — no data is sent to any server.

**Live:** https://eldanizomarov.github.io/QR-Generator/

## Features
- Ready-made templates for links, Wi-Fi, email and phone
- Dot shapes: rounded, dots, square
- Custom colors, gradient, transparent background
- Center logo (switches to high error-correction automatically so it still scans)
- Download as PNG (512–4096 px) or SVG, and copy to clipboard
- 4 languages: AZ · EN · TR · RU, light and dark themes
- Fully offline — a single HTML file plus `qrcode.js`

## How to use
1. Type your link or text.
2. Pick colors and a shape; optionally add a logo.
3. Click **Download PNG** or **SVG**.
